# ADR-002 El checklist inicial es requisito previo de la entrega
**Contexto.** El BPMN genera el checklist después de entregar; el glosario (D023) y US-07 lo listan como requisito para registrar la entrega.
**Decisión.** Se exige antes de entregar (`ChecklistSpec` dentro de `requisitos_completos`).
**Alternativas.** Generarlo después (contradice US-07 y la regla RN-02).
**Consecuencias.** El BPMN debe actualizarse en el reporte final.
